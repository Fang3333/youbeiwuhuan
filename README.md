# 邮备无患 · youbeiwuhuan

北邮校园小管家：把**课表、未交作业、校园通知**自动同步到你的**电脑 + 手机**。
一个 WorkBuddy 技能，装好后对着它问「我的日程怎么样」就行。

## 零基础用法（就两步）

**第 1 步**：让 WorkBuddy 装技能。对它说：

```
帮我从 GitHub 装 youbeiwuhuan 这个技能并部署
```

WorkBuddy 会自动：装 Node.js → 配国内镜像 → 让你填一次学号和教务密码 → 启动服务。

**第 2 步**：打开它给你的网页地址（http://127.0.0.1:3080）登录一次，手机装 App 连上（技能会一步步提示）。

以后直接问：
- 我的日程怎么样？
- 还有什么作业没交？
- 今天什么课？

## 原理（一句话）

技能里的脚本用你的学号+密码登录北邮统一认证 → 抓教学云未交作业 → 内置小管家用人话回答你。密码只存在你自己的电脑上。

## 当前进度

- ✅ 统一认证登录 + 教学云未交作业抓取（已实测）
- ✅ 一键部署脚本（国内 npm 镜像加速 + 自动装 Node）
- ⬜ 课表、校园通知抓取（开发中，见 issues）

## 目录

```
skill/youbeiwuhuan/    ← 技能本体（WorkBuddy 装的就是这个目录）
  SKILL.md             小管家的人设与部署/问答规则
  scripts/             部署与抓取脚本
  assets/              手机接入说明等
```

## 依赖与风险

- Windows 电脑 + Node.js（安装脚本会自动装），手机连 DeepSeek Harness 客户端
- 统一认证偶发要求验证码时，暂时需在电脑上人工登一次教学云
- 学号密码仅存本机、只用于登录学校系统，请勿上传到任何地方
